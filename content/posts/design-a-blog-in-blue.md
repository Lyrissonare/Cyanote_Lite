# 用「蓝」设计一个博客

## 一套色板

```css
:root {
  --accent: #3b82f6;        /* 主蓝 */
  --accent-strong: #2563eb; /* 深蓝 */
  --accent-soft: #dbeafe;   /* 淡蓝底色 */
}
```

暗色模式下把主蓝微微调亮，让它在深底上依旧清澈：

```css
[data-theme='dark'] {
  --accent: #60a5fa;
  --accent-strong: #3b82f6;
  --accent-soft: #1e3a5f;
}
```

## 两种性格

- **经典模式**：白纸黑字、留白与衬线标题 —— 安静地阅读
- **未来主义**：动态网格、霓虹描边、玻璃拟态 —— 先锋地登场

未来主义不是默认，而是一种可选的情绪。首页右上角的大门，随时为它敞开。
